# Octavia Boutique website

Single-page site for Octavia Boutique, 94 Village Square, The Village of Cross Keys, Baltimore, MD 21210.

- `index.html`: the whole site (styles and scripts inline).
- `images/`: store photos.

To add a photo, drop the file in `images/` and add an entry to the `PHOTOS` list in `index.html`.
Reviews are in the `REVIEWS` list in the same file.
